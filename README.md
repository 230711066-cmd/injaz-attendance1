# إنجاز — حضور وانصراف الموظفين بالـQR

نظام عربي لشركة الصيانة: رابط QR واحد، حساب خاص لكل موظف، سجل مشترك للإدارة، وتصدير CSV.

## النشر بالخطة المجانية

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/230711066-cmd/injaz-attendance1)

- **GitHub:** حفظ الكود فقط.
- **Render Free:** يشغل الموقع عبر HTTPS برابط ثابت دون الاعتماد على اللابتوب.
- **Supabase Free:** قاعدة PostgreSQL مشتركة تحفظ الحسابات والحركات حتى بعد إعادة تشغيل Render.

لا يحتاج هذا الإعداد خطة مدفوعة أو قرص Render مدفوع. لا تستخدم SQLite على Render Free؛ ملفاته مؤقتة وتضيع عند إعادة التشغيل. التطبيق يرفض التشغيل على Render بدون قاعدة خارجية.

### 1. قاعدة Supabase

1. ادخل [Supabase](https://supabase.com/dashboard) وأنشئ مشروعاً في منظمة **Free**. لا ترقّ الخطة.
2. اختر كلمة مرور قوية لقاعدة البيانات واحتفظ بها بشكل خاص.
3. من **Connect** اختر **Session pooler** وانسخ رابط PostgreSQL المتوافق مع IPv4 (المنفذ 5432 عادة). استخدم رابط القاعدة، وليس Project URL أو مفتاح anon.
4. ضع كلمة مرور القاعدة الحقيقية بدلاً من العنصر النائب في الرابط. إذا تضمنت رموزاً خاصة يجب URL-encode لها.

### 2. موقع Render

1. اضغط زر **Deploy to Render** أعلى الملف، وادخل بحسابك.
2. راجع أن الخدمة **Free**، وأدخل رابط PostgreSQL في حقل `DATABASE_URL` السري. لا تلصقه في GitHub أو المحادثة.
3. ينشئ الإعداد `INJAZ_SETUP_TOKEN` عشوائياً. بعد النشر افتح Environment وانسخ قيمته للإعداد الأول فقط، ولا ترسلها للموظفين.
4. افتح رابط HTTPS الذي تعرضه الخدمة، وأدخل رقم وكلمة مرور الإدارة ورمز الإعداد. لا يوجد حساب إدارة بكلمة مرور افتراضية.
5. أضف حساباً لكل موظف وسلّمه بياناته بشكل خاص.
6. احفظ رابط HTTPS في لوحة الإدارة؛ يظهر QR ثابت. اختبره من بيانات الهاتف ثم اطبعه بالشركة.

قاعدة التطبيق تستخدم مخطط PostgreSQL اسمه `injaz`، منفصل عن مخطط Supabase `public` المعرّض افتراضياً عبر Data API. الاتصال بها يتم بالخادم فقط. لا تضف مخطط `injaz` إلى exposed schemas، ولا تمنح مستخدمي anon/authenticated وصولاً إليه.

### حدود المجاني

- Render ينام بعد 15 دقيقة بدون زيارات؛ أول فتح لاحق قد ينتظر نحو دقيقة. الرابط يبقى نفسه.
- Supabase Free يوفّر 500 MB لقاعدة البيانات، ويمكنه إيقاف المشروع بعد أسبوع من قلة النشاط؛ راجع لوحة Supabase لإعادته.
- الخدمات المجانية ليست ضماناً لتوفر دائم. صدّر الحركات بانتظام وخذ نسخ PostgreSQL احتياطية خاصة. لا تفعّل ترقية أو وسائل دفع إن كنت تريد البقاء بالمجاني.
- QR يفتح صفحة تسجيل الدخول؛ مشاركته ممكنة ولا يثبت الوجود داخل مقر الشركة. لا يوجد تحقق موقع جغرافي.
- بيانات نسخة اللابتوب لا تنتقل تلقائياً. لا ترفع ملفات SQLite أو كلمات المرور إلى المستودع العام.

## التشغيل محلياً والاختبار

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s . -p 'test_*.py' -v
python serve.py
```

افتح `http://localhost:8765`. محلياً يستخدم SQLite تلقائياً إذا لم تضبط `DATABASE_URL`. إعداد الإدارة عبر loopback فقط إلا عند ضبط رمز إعداد سري. على الإنترنت يلزم `INJAZ_HTTPS=1` وخادم HTTPS أمام التطبيق.

مرجع حدود الخدمات: [Render Free](https://render.com/docs/free)، [Supabase Pricing](https://supabase.com/pricing).
