# إنجاز — حضور وانصراف الموظفين بالـQR

موقع عربي لشركة الصيانة، بحساب مستقل لكل موظف وسجل مشترك للإدارة.

## الموقع

الرابط: https://injaz-attendance1.netlify.app

يمسح الموظف QR الشركة، يدخل بحسابه، ويختار حضور أو انصراف. الإدارة تنشئ الحسابات، تشاهد السجل، تصدّره إلى CSV، وتطبع QR.

## الاستضافة المجانية

- **Netlify Free** يستضيف الواجهة وواجهات API عبر Netlify Functions.
- **Supabase Free** يحفظ قاعدة PostgreSQL بشكل مستقل عن اللابتوب وملفات النشر.
- **GitHub** يحفظ كود المشروع، بدون قاعدة الموظفين أو كلمات المرور.

ملفات النشر: [netlify.toml](./netlify.toml)، [API](./netlify/functions/api.mjs)، [الواجهة](./portal.html).

### إعداد حساب جديد

1. أنشئ مشروع Supabase Free. اختر Session pooler من Connect واحفظ رابط PostgreSQL بكلمة المرور الحقيقية.
2. أنشئ مشروع Netlify Free. أضف متغيري `DATABASE_URL` و`INJAZ_SETUP_TOKEN` كأسرار للخادم، وليس للواجهة.
3. شغّل `npm ci` ثم `node build.mjs`، وانشر مجلد `public` ووظائف `netlify/functions` باستخدام إعداد Netlify الموجود.
4. افتح الموقع وأنشئ حساب الإدارة برمز الإعداد الخاص. لا يوجد حساب أو كلمة مرور افتراضية بالمستودع.
5. أضف الموظفين واحفظ رابط HTTPS النهائي في لوحة الإدارة حتى يظهر QR للطباعة.

حساب الإدارة المنقول من نسخة اللابتوب يحتفظ ببياناته القديمة. هذه البيانات ليست موجودة في GitHub.

### الحماية والبيانات

كلمات المرور مخزنة باستخدام PBKDF2، والجلسات بكوكي HttpOnly/Secure. يسجل الخادم الوقت بتوقيت بغداد، ويؤكد العملية بعد حفظ المعاملة. يمنع تكرار الحضور والانصراف المتتاليين، ويسمح باستمرار الوردية عبر منتصف الليل.

قاعدة التطبيق في مخطط `injaz` غير المعرض عبر Supabase Data API. اتصال Node يتحقق من شهادة الخادم باستخدام شهادة Supabase العامة المرفقة. لا تضف مخطط التطبيق إلى API المكشوف، ولا ترفع ملفات `.env` أو SQLite أو بيانات الإدارة إلى المستودع.

QR ثابت يفتح صفحة تسجيل الدخول؛ لا يثبت وحده وجود الموظف داخل الشركة، ويمكن مشاركة الرابط. لا يوجد تحقق GPS.

### حدود المجاني

Netlify Free له رصيد استخدام شهري محدود؛ قد يتوقف الموقع إذا نفد الرصيد. Supabase Free قد يوقف المشروع بعد أسبوع من قلة الاستخدام ويمكن إرجاعه من اللوحة. لا توجد نسخ قاعدة احتياطية تلقائية مضمونة بالخطة المجانية؛ صدّر السجل وخذ نسخاً احتياطية خاصة دورياً.

المراجع: [Netlify Free](https://www.netlify.com/pricing/)، [Supabase Free](https://supabase.com/pricing/).

## الاختبار والتطوير

```sh
npm ci
node build.mjs
node --test test_api.mjs
```

اختبار API يحتاج `INJAZ_TEST_DATABASE_URL` لقاعدة اختبار، وينشئ مخطط اختبار منفصلاً ثم يحذفه. بدون الاتصال يظهر الاختبار skipped. يوجد أيضاً فحص تلقائي على GitHub بقاعدة PostgreSQL مؤقتة.

توجد نسخة Python للمعاينة المحلية في [server.py](./server.py) و[serve.py](./serve.py). لا تستخدم SQLite على استضافة بملفات مؤقتة.
